🔄 ES 수학 — Firebase 이전 복구

백업 엑셀 파일을 새 Firebase 프로젝트로 완전 이전합니다.

⚠️ 이 도구는 새 Firebase 프로젝트로 이전할 때 사용합니다.
• 새 Firebase 콘솔에서 프로젝트를 생성하고 Firestore를 활성화한 뒤 사용하세요.
• Firebase 설정 값(apiKey 등)은 Firebase 콘솔 → 프로젝트 설정 → 내 앱에서 확인할 수 있습니다.
• 복구 완료 후 index.html의 firebaseConfig를 새 값으로 교체해야 앱이 정상 동작합니다.
